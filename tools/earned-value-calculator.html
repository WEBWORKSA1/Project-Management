Earned Value Calculator

Enter four numbers and get every earned value metric — plus a plain-English verdict you can paste straight into a status report.

Inputs

EV = BAC × % of work actually complete. PV = BAC × % of work that should be complete by now.

Worked example

A $200,000 project should be 45% done (PV = 90,000) but is only 40% done (EV = 80,000), and 95,000 has been spent (AC). CPI = 80 ÷ 95 = 0.84 and SPI = 80 ÷ 90 = 0.89. The project is over budget and behind schedule. At the current efficiency it will cost about 237,500 — roughly 37,500 over budget. Read the full earned value management guide.

Frequently asked questions

What do CPI and SPI mean?

CPI (cost performance index) = EV ÷ AC; above 1.0 means under budget. SPI (schedule performance index) = EV ÷ PV; above 1.0 means ahead of schedule.

What is the difference between PV and EV?

Planned Value is the budgeted cost of the work scheduled to be done by now. Earned Value is the budgeted cost of the work actually completed by now.

Which EAC formula should I use?

Use BAC ÷ CPI when current cost performance is expected to continue (most common). Use AC + (BAC − EV) when the variance was a one-off. Use the CPI × SPI version when schedule pressure will also affect cost.
