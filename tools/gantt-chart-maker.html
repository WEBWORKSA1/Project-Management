How to make a Gantt chart in 5 steps

  1. List the work. Start from your work breakdown structure. Each row should be a task someone can own and finish, ideally 1–10 days long.
  2. Estimate durations. Use working days. If you are unsure, use the PERT estimator to turn optimistic, likely and pessimistic guesses into one number.
  3. Link dependencies. In Depends on, type the row numbers that must finish first. The chart pushes start dates forward automatically.
  4. Mark milestones. Zero-duration events such as "Design sign-off" or "Go-live" show as diamonds. They make status reports easy to read.
  5. Track progress weekly. Update the % complete column. The weighted progress figure weights each task by its duration, so long tasks count more.

When a Gantt chart is the right tool

Gantt charts work best when the sequence of work matters: construction, events, product launches, migrations, regulatory deadlines, or any project with hand-offs between teams. For continuous-flow work with shifting priorities, a Kanban board is usually better. Many teams use both: a high-level Gantt for milestones and a board for day-to-day work.

Common Gantt chart mistakes

  • Too much detail. 300 rows nobody updates helps no one. Keep the plan at a level you will actually maintain.
  • Missing dependencies. Without links the chart is just a drawing. When one date slips, nothing else moves and the plan lies.
  • No buffer. Find your critical path and protect it with contingency rather than padding every task.

Frequently asked questions

How do dependencies work in this Gantt chart maker?

Type the row numbers of predecessor tasks in the Depends on column (for example 2,3). The tool uses finish-to-start logic: a task cannot start before all of its predecessors finish, so its start date moves forward automatically.

How do I add a milestone?

Tick the Milestone box or set the duration to 0. Milestones appear as diamonds on the chart.

Can I open the export in Excel or Google Sheets?

Yes. The CSV export opens directly in Excel, Google Sheets, Numbers and most PM tools that accept CSV imports.

Is my data private?

Yes. Your tasks are stored only in your browser's local storage on this device and are never uploaded.
