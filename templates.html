Which template do I need?

  • Starting a project? Charter → stakeholder register → RACI → project plan.
  • Running it? Status report weekly, issue log and risk register reviewed in every status meeting, change requests for any scope change.
  • Controlling money? Budget tracker monthly, plus the earned value calculator.
  • Finishing? Lessons learned log at each phase gate, not only at the end.
